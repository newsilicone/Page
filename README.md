# NEW SILICONE

Web comercial de una página con navegación por secciones, catálogo y un formulario que prepara un mensaje de cotización en el navegador. Abre `index.html` para revisarla.

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub y sube los archivos extraídos del ZIP. Coloca `index.html`, `styles.css`, `app.js` y la carpeta `assets` en la raíz del repositorio.
2. Entra en **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/ (root)**, guarda y abre la dirección que aparece en **Settings → Pages**.

La web funciona con HTML, CSS y JavaScript sin pasos de compilación. Los recursos usan rutas relativas para funcionar en la URL del repositorio.

## Actualizar el contacto

En `index.html`, la sección `contactenos` incluye el enlace público a TikTok. Puedes añadir el WhatsApp comercial o Messenger allí cuando tengas la URL oficial. El formulario prepara texto para copiar. El visitante envía el mensaje desde el canal de contacto.
